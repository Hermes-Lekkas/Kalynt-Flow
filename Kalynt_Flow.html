// the pipeline

One thread, six stages.

Everything that happens to a piece of work — from the moment it's filed to the moment it ships — lives on the same line.

01
stage/tasks
Tasks that track real work
Create, assign and prioritize tasks per workspace — filed straight from a GitHub issue or written from scratch.
02
stage/notes
Notes attached to context
Design decisions, meeting notes and PR discussion live next to the task they belong to, not in a separate app.
03
stage/calendar
A calendar that knows your deadlines
Ship dates, syncs and reviews on one shared calendar — filtered by workspace, not buried in someone's inbox.
04
stage/chat
Chat scoped to the work
Talk to your team inside the workspace the conversation is actually about — no channel-hunting.
05
stage/companion
An AI companion that does the admin
Ask it to draft a task, summarize a thread, or schedule the next sync — it writes to your workspace directly.
06
stage/shipped
Shipped, without re-typing anything
Close the loop back on GitHub. Status flows both ways into the one place your team already looks.
// github sync

Your repo, mirrored — not duplicated.

Connect a repository once. Issues and pull requests show up as tasks and notes automatically.

-issue #114 "Fix onboarding crash"
+task · Fix onboarding crash · assigned
-pr #89 → main
+note · linked to task #114 · open
-3 commits pushed
+calendar · activity logged today
Read-only, on purpose.
Kalynt Flow mirrors GitHub — it never force-pushes changes back into your repo.
Sign in with the account you already have.
GitHub auth runs through the same secure sign-in as the rest of the app.
Link as many repos as your workspace needs.
Each one syncs independently, with its own status at a glance.
